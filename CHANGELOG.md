# Changelog

## 0.1.0 · 2026-10

First public version. Generalised from a private plugin used daily since August 2026.

- `setup`: vault scaffold, connector check, read-only Salesforce org fingerprint
- `meeting-intake`: transcript to stub, vault proposals, Salesforce proposals, action items
- `account-brief`: five minute brief combining Salesforce, transcripts and the vault
- `opp-review`: pipeline health check with the honesty rule and "said but not logged"
- `contact-sync`: mention triggered contact pages, two way Salesforce check
- `vault-update`: account and opportunity pages with read before write
- `vault-lint`: weekly drift audit, including drift against Salesforce
